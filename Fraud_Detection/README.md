# Machine Learning Project: Clustering and Classification

Proyek ini menerapkan pendekatan unsupervised learning dan supervised learning.

## Tujuan Proyek

1. Melakukan Exploratory Data Analysis.
2. Melakukan preprocessing data.
3. Membangun model clustering menggunakan K-Means.
4. Menggunakan hasil clustering sebagai label target.
5. Membangun model klasifikasi menggunakan Decision Tree dan Random Forest.
6. Melakukan evaluasi model klasifikasi.
7. Melakukan hyperparameter tuning.

## Struktur Proyek

- `data/raw/` berisi dataset asli.
- `data/processed/` berisi dataset hasil preprocessing dan clustering.
- `notebooks/` berisi notebook clustering dan klasifikasi.
- `models/` berisi model hasil training.
- `outputs/` berisi visualisasi dan laporan.
- `src/` berisi kode modular.
